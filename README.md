#  Student Record Management System

A console-based **Student Record Management System** written in **C programming language** that allows users to store, manage, and analyze student data efficiently.

This project demonstrates structured programming, data handling, and problem-solving techniques using C.

---

##  Project Overview

The system enables users to:

- Store student records
- Search and display student information
- Analyze grades and performance
- Perform calculations such as averages and grade comparisons

It is designed as a **menu-driven application** for easy interaction.

---

##  Features

###  Student Management
 Add new student records  
 Store ID, name, age, and grades  

###  Data Display & Search
 Display all students  
 Search student by ID  

###  Grade Analysis
 Find **maximum and minimum grades**  
 Display grades for a specific course  
 Calculate **average grade** for a student  

---

##  Data Structure

Each student record includes:

- Student ID  
- Name  
- Age  
- Grades for 3 courses  

The system supports up to **100 students**.

##  How It Works

### 🔹 Insert Student
Allows the user to enter student information and grades.

### 🔹 Display Students
Shows all stored student records.

### 🔹 Search Student
Finds a student using their ID.

### 🔹 Max & Min Grades
Identifies the highest and lowest grades stored.

### 🔹 Course Grades Display
Shows all students' grades for a selected course.

### 🔹 Average Grade
Calculates the average grade for a specific student.

1. Open terminal or command prompt
